# Decentralized Energy Trading Network

## Project Description

The Decentralized Energy Trading Network is a blockchain-based platform that enables peer-to-peer energy trading between energy producers (such as homeowners with solar panels) and consumers. Built on Ethereum, this smart contract system eliminates the need for traditional energy utilities as intermediaries, allowing direct energy transactions with transparent pricing and automated settlements.

The platform leverages smart contracts to facilitate secure, transparent, and efficient energy trading while providing real-time access to energy availability and pricing information across the network.

## Project Vision

Our vision is to democratize the energy market by creating a decentralized ecosystem where:

- **Energy Independence**: Individual households and small businesses can become energy entrepreneurs
- **Fair Pricing**: Market-driven pricing mechanisms ensure competitive rates
- **Sustainability**: Incentivizes renewable energy production and consumption
- **Transparency**: All transactions are recorded immutably on the blockchain
- **Accessibility**: Anyone can participate as either a producer or consumer
- **Efficiency**: Reduces energy waste through optimized local distribution

## Technical Implementation

### Core Smart Contract Functions

1. **`listEnergy()`**: Allows producers to list energy for sale with custom pricing
2. **`purchaseEnergy()`**: Enables consumers to buy energy directly from producers
3. **`withdrawEarnings()`**: Secure withdrawal system for producers to claim earnings

### Contract Architecture
- **Producer Management**: Registration, energy tracking, and pricing
- **Transaction Processing**: Secure payment handling and energy allocation
- **Balance Management**: Segregated accounting for all participants
- **Event Logging**: Comprehensive transaction and activity tracking

## Installation & Deployment

### Prerequisites
- Node.js (v14 or higher)
- Hardhat or Truffle framework
- MetaMask or similar Web3 wallet
- Solidity compiler v0.8.19+

### Quick Start
```bash
# Clone the repository
git clone <repository-url>
cd Decentralized-Energy-Trading-Network

# Install dependencies
npm install

# Compile contracts
npx hardhat compile

# Deploy to local network
npx hardhat run scripts/deploy.js --network localhost

# Run tests
npx hardhat test
```
